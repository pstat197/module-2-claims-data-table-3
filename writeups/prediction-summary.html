Predictive modeling of claims status

Author

Calder Glass, Andrew Guerra, Lorretta Lu, Justin Zhou, Wendy Zhu

Published

November 19, 2025

Abstract

We analyzed the text content of web pages to predict the classification of insurance claims. To do so, we relied on text data as our input data, which was scraped from HTML, cleaned, and processed into TF-IDF vector representations. For both binary and multiclass predictions, we utilized feed-forward neural networks with Keras. After constructing and evaluating our models, we found that the binary model achieved an estimated accuracy of 81.5% on the test data, while the multiclass model achieved an estimated accuracy of about 77%.

Preprocessing

Our preprocessing pipeline helped extract meaning out of raw web content. To do so, we transformed raw web content into numerical vectors that we can feed to our neural network models. We began by extracting the main textual content from each webpage by selecting paragraph elements from the raw HTML and removing all structural markup. The extracted text was then cleaned by removing URLs, emails, punctuation, digits, symbols, extra whitespace, and by converting all text to lowercase to ensure consistent token matching. After cleaning, we applied the Keras function, ‘layer_text_vectorization()’, which converted our text into numeric tensors using TF-IDF as the output and splitting the text by whitespace. Through this process, we created vectors that reflect the relative importance of word elements within each document compared to the overall set of documents.

After cleaning, the text was tokenized into individual words and transformed into a quantitative representation using term frequency-inverse document frequency (TF-IDF), yielding a high-dimensional numerical feature matrix suitable for statistical modeling. In Preliminary Task 1, we further reduced this feature space using principal component analysis (PCA) so that the model operated on a smaller set of orthogonal text-derived components rather than the full TF-IDF vocabulary.

Methods

Using Keras and TensorFlow, we developed two separate neural network models. Our first model, the Binary Classification Model, was implemented with a sequential neural network. The architecture consisted of a TF-IDF text vectorization layer, followed by a hidden layer of 16 units. To prevent overfitting our model, we added a dropout layer with a rate of 0.3, followed by a second dense layer with 8 units. The output layer used a single unit with a sigmoid activation function to produce a score between 0 and 1. The model was then compiled with the Adam optimizer and binary cross-entropy loss, and trained for 15 epochs with a 20% validation split. For the Multiclass Classification Model, we used a larger framework that used a dense layer of 32 units after the TF-IDF layer. The dropout layer rate remained at 0.3 and the second dense layer included 16 units. The output layer consistent of 5 units with a softmax activation function. This model was compiled using the Adam optimizer and categorical cross-entropy loss.

Results

For the binary classification model, predictive performance was evaluated on the held-out test set using accuracy, sensitivity, and specificity. The logistic PCR model achieved an overall accuracy of 0.815, with a sensitivity of 0.802 and a specificity of 0.831.
